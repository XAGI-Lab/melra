# Research and benchmarks

MELRA publishes a narrow claim only when the implementation, harness,
input revision, metric, and raw result are inspectable. A fast action is not
necessarily a correct action, retrieval coverage is not answer accuracy, and
a component microbenchmark is not a task leaderboard.

## External benchmark map

These primary sources define the representative evaluations we track:

- [LongMemEval](https://github.com/xiaowu0162/LongMemEval) evaluates
  information extraction, multi-session reasoning, knowledge updates,
  temporal reasoning, and abstention over 500 long histories.
- [LoCoMo](https://github.com/snap-research/locomo) provides ten long
  conversations and question annotations with evidence dialogue IDs.
- [BrowserGym](https://github.com/ServiceNow/BrowserGym) provides unified
  environments including WebArena, WebArena-Verified, VisualWebArena, and
  WorkArena.
- [OSWorld](https://github.com/xlang-ai/OSWorld) measures execution-based
  success on real computer tasks.
- [OSWorld-MCP](https://arxiv.org/abs/2510.24563) measures MCP tool
  invocation together with GUI operation and decision-making.
- The [MCP tools specification](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)
  recommends a human in the loop for tool invocations, and the official
  [security guidance](https://modelcontextprotocol.io/docs/tutorials/security/security_best_practices)
  documents MCP-specific attack classes.

MELRA does not claim an external benchmark score unless its exact public
evaluation has been run and released.

## Reproduction

```bash
pnpm benchmark:core
pnpm benchmark:govbench

git clone https://github.com/snap-research/locomo.git /tmp/locomo
pnpm benchmark:locomo -- \
  --dataset /tmp/locomo/data/locomo10.json \
  --output docs/research/results/locomo-retrieval.json

pnpm benchmark:browser:check
pnpm benchmark:browser:verify-upstream

uv run --project benchmarks/browser-agent \
  --extra miniwob --extra webarena --group test \
  pytest benchmarks/browser-agent -q
```

LoCoMo data is not vendored because it has its own CC BY-NC 4.0 license.
